About This Project

How the Insider Buying Tracker works, what it looks for, and what it doesn't do
Disclaimer This project is a personal hobby tool built for fun and learning. It is not investment advice of any kind. The data comes from public SEC filings and may contain errors, omissions, or misparses. Insider buying is one data point among many — it is not a reliable predictor of future stock performance, and many historically high-scoring insider buys have resulted in losses. Do not make investment decisions based on this tool. Past results have no predictive value. The author may or may not have a financial interest in any companies shown.

What This Is

Corporate insiders — executives, directors, and large shareholders — are required by the SEC to publicly disclose when they buy or sell shares of their own company using Form 4. This tool automatically pulls those filings twice a week, filters them down to open-market purchases specifically, enriches them with company context and price charts, and publishes a report.

The core thesis is simple: insider sales are noisy. Executives sell for a hundred different reasons — estate planning, taxes, diversification, a divorce, a new house. Insider buys are different. There is almost no reason to go into the open market and spend your own money buying your company's stock unless you genuinely believe it is undervalued. This tool tries to separate that signal from the noise of the broader Form 4 filings.

It is not trying to be comprehensive market research. It is a structured way of seeing what insiders are doing with their own money, filtered and ranked so the most interesting buys surface first.

The Pipeline

The pipeline runs automatically every Tuesday and Friday at 6 AM Mountain Time via GitHub Actions. Each run covers a rolling 7-day window, so Tuesday's report and Friday's report are independent snapshots rather than an accumulated weekly total.

  1. Fetch Form 4 filings — SEC EDGAR Query the SEC full-text search index for all Form 4 filings in the 7-day window. For each filing, download the raw XML and extract every non-derivative transaction where the transaction code is P (open-market purchase) and the acquired/disposed code is A (acquired). Output: a JSON file of raw transactions.
  2. Enrich — Polygon.io For each unique ticker in the raw data, call Polygon to get the company description, sector, market cap, and recent news headlines. Company details are cached for 30 days (they rarely change); news is always fresh. Tickers are prioritized by transaction value so the most significant buys get enriched first if the API budget runs short.
  3. Generate price charts — Polygon.io For the top-ranked companies (those that will get a full card in the report), fetch 6 months of daily price data and generate a chart showing the price line, 50-day and 200-day moving averages, and vertical markers on each insider buy date. Charts are encoded as base64 and embedded directly in the HTML — no external image hosting needed.
  4. Score and rank Apply a scoring heuristic to each transaction based on dollar value, percentage position increase, insider role, and whether multiple insiders at the same company bought in the same window (a "cluster buy"). See the scoring section below for the full breakdown.
  5. Generate the report Render a self-contained HTML report. The top 15 transactions by score get a full card with company description, recent headlines, and a price chart. Everything else appears in a sortable summary table. The index page is rebuilt with a link to the new report.
  6. Update the performance tracker Record the closing price of each flagged stock on the report date (using Polygon's grouped daily endpoint — one API call returns prices for all US stocks simultaneously). On each subsequent run, fetch the latest prices and compute how each flagged buy has performed since it was flagged.

Form 4 Filings — What They Are and What Can Go Wrong

Form 4 is a mandatory SEC disclosure filed by corporate insiders within two business days of any transaction in their company's securities. Each filing contains the insider's identity, their relationship to the company (officer, director, 10%+ owner), the security type, and one or more transaction records detailing the date, shares, price, and a transaction code describing the type of transaction.

The raw filing feed is noisy. Here are the most common problems and how this pipeline handles each one.

Non-purchase transactions look like purchases
Most Form 4 transactions are not open-market purchases. Grants (A), option exercises (M, X), tax withholding (F), gifts (G), and other non-economic transfers all show up in the same filing structure and at a glance look similar to real purchases.
The pipeline filters strictly to transaction code P (open-market purchase) combined with acquired/disposed code A (acquired). Every other transaction type is discarded entirely.
Amended filings (Form 4/A)
An insider can file a corrected Form 4, called a 4/A, days or weeks after the original. Without handling this, the same transaction appears twice — once from the original filing and once from the amendment — inflating counts and potentially showing a corrected price alongside the wrong original price.
Transactions are keyed by accession number and position index within the filing (accession:index). When a 4/A is processed, its accession key overwrites the matching original entry rather than appending a new one.
Missing or footnoted prices
SEC rules allow the price field to be blank if the price is described in a footnote (common for transactions executed under a 10b5-1 plan, or when the exact price is a weighted average across multiple trades). A missing price makes it impossible to compute total transaction value.
Transactions with null prices are retained rather than discarded — a large share count without a stated price is still informative. They appear in the report with "N/A" for value-based fields and receive a reduced score since value-tier scoring cannot apply.
10% owners are a different signal than officers
Large funds and activist investors holding 10%+ of a company must also file Form 4. Their purchases are often portfolio rebalancing, index reconstitution, or follow-on investments in a company they already control — not a vote of confidence from someone with operational insight into the business.
10% owners receive zero role-based scoring points (compared to +1 for directors and +2 for C-suite officers). They still appear in the report if their transaction value is large, but they score lower and are harder to surface above genuine officer buys.
Derivative securities vs. direct share purchases
Form 4 contains two tables: one for non-derivative securities (actual shares) and one for derivatives (options, warrants, convertible notes). An executive exercising options and simultaneously purchasing shares might look like a very large buy in aggregate.
Only the non-derivative table is processed. Derivative transactions of any kind are ignored entirely, regardless of transaction code.
Missing ticker symbols
The ticker symbol in a Form 4 XML filing is provided by the filer and is sometimes blank, misspelled, or stale (the company has since been acquired or renamed). Without a ticker, Polygon enrichment and chart generation are impossible.
The SEC publishes a CIK-to-ticker mapping file that is refreshed weekly. Any transaction with a blank ticker field is resolved against this mapping using the issuer's CIK. Transactions that remain unresolved after this step are included in the report table but skipped for Polygon enrichment.
Filing date vs. transaction date
Insiders have up to two business days to file after a transaction. The filing date and the transaction date can differ by several days. A purchase made on Monday might only appear in the system on Wednesday.
Both dates are stored and displayed. The 7-day rolling window uses the filing date for retrieval (since that is what EDGAR indexes), but the report shows the transaction date as the date the insider actually bought. Price charts mark the transaction date, not the filing date.

Scoring

Each transaction receives a score between 0 and ~14 based on four independent signals. Scores are additive — a transaction can qualify for points in multiple categories simultaneously. The scoring weights are all configurable in config.yaml.

Dollar Value — Skin in the Game

The most direct measure of conviction is how much the insider actually spent.

Transaction ValuePointsRationale
≥ $1,000,000+3Significant personal commitment. Hard to dismiss as routine.
≥ $500,000+2Meaningful but not outsized.
≥ $100,000+1Above the noise floor. Worth tracking.
< $100,000+0Potentially routine or nominal. Still shown in the table.

Position Increase — Proportional Conviction

A $50,000 purchase by someone who already holds $10 million of stock is less interesting than the same purchase by someone doubling their position from scratch. This signal measures how much the insider's stake grew as a percentage of their pre-purchase holding.

Position IncreasePointsRationale
≥ 50% increase+2The insider dramatically increased their exposure.
≥ 25% increase+1A meaningful proportional increase in skin in the game.
< 25% increase+0Incremental add-on. Less meaningful on its own.

Role — Information Advantage

An insider's informational advantage depends on their role. The CEO and CFO have the clearest view of the business's trajectory. A board director has less day-to-day visibility. A 10% owner is often an institutional investor with no operational insight at all.

RolePointsNotes
C-suite officer (CEO, CFO, COO, CTO, President)+2Highest operational visibility.
Other officer+1EVP, SVP, GC, VP-level roles.
Director+1Board-level visibility without daily operations.
10%+ owner only+0Often fund rebalancing with no operational insight.

Cluster Buys — The Strongest Signal

When multiple insiders at the same company independently purchase shares in the same week, it is rarely a coincidence. Each insider made the decision separately; each one looked at the same business and reached the same conclusion. Academic research consistently shows that cluster insider buying is one of the highest-signal patterns in public market data.

SignalPointsNotes
≥ 2 distinct insiders buying the same company in the same window +3 Applied to every qualifying transaction at that company. A 3-insider cluster adds +3 to each of the three transactions individually.

Cluster buys are also visually separated in the report — they appear before the ranked individual buys section, regardless of absolute score.

Data Sources

SEC EDGAR — Form 4 Filings
The primary data source. Free, no API key required. Rate limit: 10 requests/second.
  • EFTS full-text search (efts.sec.gov) — indexes all filed documents and supports date-range queries by form type. Returns filing metadata and the name of the primary XML document.
  • Filing XML (www.sec.gov/Archives/edgar/data/…) — the actual Form 4 document parsed to extract transaction details, insider identity, and company information.
  • CIK-to-ticker mapping (www.sec.gov/files/company_tickers.json) — maps SEC company identifiers to stock tickers. Refreshed weekly.
Polygon.io — Market Data
Used for company context and price data. Free tier: 5 API calls/minute. The pipeline is designed around this constraint.
  • Ticker Details V3 — company description, SIC sector code, market cap, employee count. Cached per ticker for 30 days.
  • Ticker News — the 5 most recent news headlines for each company. Always fetched fresh (not cached).
  • Aggregates (daily bars) — 6 months of daily OHLCV data used for chart generation. Also provides current price and 52-week range.
  • Grouped Daily — one API call returns closing prices for all US stocks on a given trading day. Used by the performance tracker to snapshot prices at each report date and compute subsequent returns.

Polygon calls are interleaved per ticker: for each company, all three calls (details, news, aggregates) are made together before moving to the next. This ensures every company that gets enriched also gets a chart. If the API budget runs out mid-run, the remaining companies appear in the report without Polygon data rather than having mismatched partial enrichment.

Tickers are prioritized by transaction value before enrichment begins, so the highest-value buys are enriched first. The pipeline caps enrichment at 80 unique tickers per run to avoid runaway API usage during high-volume weeks like earnings season.

What This Tool Does Not Do

  • It does not track insider sales. Sales are intentionally excluded as a noisy signal.
  • It does not normalize for market conditions. A buy during a broad market selloff scores the same as a buy in a rally.
  • It does not track insider track records over time. There is no history of which insiders have been right before.
  • It does not cross-reference with 13F filings, earnings calendars, or other public disclosures.
  • It does not filter out 10b5-1 plan purchases (pre-scheduled automatic buy programs), which are less discretionary than truly spontaneous purchases. The SEC does not always distinguish these clearly in Form 4 XML.
  • It is not real-time. There is a 2–5 day lag between when a transaction occurs and when it appears in a report.
